##  Featured Projects

###  [NutriRecall](https://github.com/Sneha-pixel21/NutriRecall) — AI-Powered Personal Health Intelligence
> `Python` · `Streamlit` · `SQLite` · `Groq API` · `Ollama` · `Plotly`

A full-stack health tracking system with a **RAG pipeline** at its core. Logs daily metrics (weight, protein, sleep, workouts) and generates personalized insights — not generic advice, but answers grounded in *your own data*. Supports both cloud (LLaMA via Groq) and local (Ollama) LLM backends with dynamic switching.

---

###  [RAG PDF Question Answering](https://github.com/Sneha-pixel21/RAG-PDF-Answering-Model) — Query Your Documents
> `Python` · `ChromaDB` · `Sentence Transformers` · `Ollama` · `Gradio`

End-to-end RAG system for extracting insights from PDF documents using **semantic search + vector embeddings**. Built with a local LLM backend and a multi-document Gradio interface. Heavy focus on prompt engineering for accuracy and relevance.
